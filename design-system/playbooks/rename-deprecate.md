# 플레이북: 이름 변경과 폐기

토큰을 바로 지우거나 이름을 바꾸면 이를 참조하던 Figma 파일과 코드가 한꺼번에 깨집니다. 두 단계로 나눠 진행합니다.

## 1단계 — 새 이름 추가, 이전 이름 폐기 예정 (MINOR)

1. Figma에 새 이름의 배리어블을 만든다. 모든 모드의 alias를 이전 토큰과 같게 둔다.
2. 이전 배리어블의 설명 앞에 `[Deprecated → 새 이름]`을 붙인다. 스코프를 모두 꺼서 피커에서 숨긴다.
3. 문서에 새 항목을 추가하고, 이전 항목의 상태 필드를 `- 상태: deprecated → 새 이름` 형식으로 바꾼다.
4. [CHANGELOG.md](../CHANGELOG.md)의 폐기 예정 표에 행을 추가한다.
5. 내보내기 → `npm run tokens:sync` → `npm run tokens:check`

## 2단계 — 사용처 교체

- Figma: 이전 배리어블을 쓰는 레이어를 찾아 새 배리어블로 바꾼다.
- Component 토큰: 이전 이름을 참조하는 alias를 새 이름으로 바꾼다 (CHK-13 경고가 사라지는지 확인).
- 코드: 이전 코드 이름(`--color-...`)을 검색해 바꾼다.

## 3단계 — 이전 이름 삭제 (MAJOR)

1. 사용처가 0인지 확인한다.
2. Figma에서 이전 배리어블을 지우고, 문서 항목도 지운다.
3. CHANGELOG의 폐기 예정 표에서 행을 지우고 해당 버전의 "삭제"에 기록한다.

## 하지 않는 것

- 1단계 없이 바로 이름을 바꾸지 않는다.
- 이전 항목의 문서를 1단계에서 지우지 않는다. 문서와 배리어블은 항상 1:1이다 (CHK-08).
